# Focal-person guide

Sign in with your privately provided account. For a private device, choose offline preparation. The Overview shows server-received reports separately from saved device drafts.

1. Choose New report. Select a new item or an existing project/issue for a follow-up visit.
2. Add title/type/sector, assigned LGA, community, landmark and visit date. GPS is optional.
3. Describe what was visible, select observed progress and add optional duty bearer, next action, source note and photographs. Use fictional evaluation information. Avoid unnecessary personal details.
4. Check the summary. Save draft keeps work on this device. Send report uploads/validates selected photos, submits one revision and returns a server reference. Until a receipt exists, the report is not received.

Drafts & sending lets you resume, explicitly send, retry, copy or discard local drafts. Failed sends preserve the content. Signing out warns and clears your local work after confirmation. Session expiration preserves it for your own reauthentication. Another account cannot see those drafts.

Open My reports to see a report's current state, photos, messages and revision history. If more information is requested, update the observation, explain your response and resubmit. An approved snapshot cannot be edited directly; request an amendment or make a genuinely later follow-up visit from the item page.

Report approval and the project's confirmed progress are separate. For connectivity, shared-device limits and restart behavior, see `offline-behaviour.md`.
