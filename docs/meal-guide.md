# Data / MEAL guide

The overview uses your current LGA assignments. Apply common search, LGA, sector, date, type and status filters. Counts, report lists and exports use the same population; the trend is first submissions by WAT day. The displayed review/progress states are current, not historical end-of-period reconstructions.

Open Reports & review. A submitted report must enter In review before verification, clarification or rejection. Read the observation and photos. Add a specific question for clarification or a reason for verification/rejection. Decisions are tied to the displayed revision/version and stale saves are rejected. Use the comparison control to inspect current server content without losing your reason.

Conversation messages are shared with the author unless Internal note is checked. Internal notes never appear in focal-person reads. MEAL cannot approve a report, reopen an approved/rejected/verified state reserved for administration, review their own report, or change confirmed item progress.

On a tracked item, record follow-up actions with an organisation, due date, status and completion note. A new visit is a separate report on the same item. Download CSV/Excel/PDF from Reports & review; exports contain all matching permitted reports within the 20,000-row limit.
